使用场景

流媒体与内容访问

适合需要稳定解锁的观影与播客场景。旗舰版强调全节点原生流媒体能力，减少地区限制带来的反复切换。

游戏与实时对战

对延迟敏感的用户可优先考虑带 IPLC 优化的方案，把游戏线路与日常浏览线路分开选择，避免高峰拥堵互相影响。

远程办公与资料协作

跨境会议、代码仓库与网盘同步依赖持续在线。团队版提供更高设备上限与定制路由，方便把办公网段与个人设备隔离。

学习研究与轻量浏览

文献站点、公开课与常规网页访问，基础版的流量与三设备额度通常足够，先跑通客户端再决定是否升级。

配置流程

猫尾酒馆把配置拆成可核对的步骤，按顺序做完即可完成机场订阅导入。若某一步失败，先回到对应步骤检查，而不是反复重装软件。

  1. 在套餐区确认流量、设备数与是否需要 IPLC 或定制路由，完成开通。
  2. 进入用户中心复制订阅链接，保持链接私密，不要发到公开群组。
  3. 根据系统选择客户端：Windows / macOS 可用 Clash Meta 或 Stash，Android 可用 Clash 系，iOS 常用 Shadowrocket 或 Quantumult X。
  4. 在客户端选择从 URL 更新或导入订阅，等待节点列表刷新完成。
  5. 先选延迟较低的日常节点测试网页，再切到流媒体或游戏策略组。
  6. 开启系统代理或 TUN 模式，确认浏览器与应用都走同一套规则。

流程核对要点

系统时间需准确，证书与核心版本保持更新。若导入后节点为空，优先检查订阅是否过期或被截断。

同一订阅占用设备数计入同时在线，不要在多台设备反复重复登录测试。

规则建议采用分流：国内直连、国外代理、流媒体独立策略，减少无效绕行。

常见问题

如何开通猫尾酒馆机场订阅？

选择基础版、旗舰版或团队版完成支付后，到用户中心复制订阅链接。将链接导入客户端并更新节点，即可按配额使用。年付仅改变结算周期，不改变当月流量计算方式。

客户端下载后如何确认导入成功？

订阅更新完成应出现节点列表与策略组。打开一个境外站点测试，同时观察流量是否增长。若列表为空，检查链接完整性、本地时间以及客户端是否支持该订阅格式。

流量与设备数如何理解？

基础版每月 100GB、3 台在线；旗舰版 300GB、5 台；团队版 1000GB、20 台。同时在线指同一时刻保持连接的终端数量。流量按套餐周期重置，上传下载合计计入。

游戏加速应选哪条路径？

对延迟敏感时优先旗舰版或团队版中的 IPLC 游戏优化节点，先测延迟再进游戏。避免在普通浏览节点上开启全局模式打实时对战，以免高峰拥塞影响手感。

流媒体提示不支持地区怎么办？

切换到标明原生解锁的节点，并关闭可能干扰的本地 DNS 或增强模式。旗舰版强调全节点原生流媒体解锁，仍失败时更新订阅后再试同一线路的备用入口。

连接反复断开如何排查？

先更新订阅，再更换协议或邻近区域节点。检查系统代理是否被其他软件抢占，关闭冲突的加速工具。团队场景建议固定办公策略组，减少频繁切换。
